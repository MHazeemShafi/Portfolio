# PORTFOLIO — Mohammed Hazeem Shafi

A personal developer portfolio built with **React and Vite**, featuring a Neo-Brutalist design, smooth scroll animations, interactive project showcases, and a custom cursor.

**Live Website:** https://hazeemshafi.vercel.app/

## Overview

This portfolio showcases my development journey, technical skills, projects, education, and certifications through a bold, minimal, and interactive interface.

## Features

- Neo-Brutalist visual design
- Responsive layout for desktop and mobile
- Custom animated cursor
- Smooth scrolling and scroll-reveal animations
- Animated typography and marquee elements
- Interactive project catalogue with category filters
- Project previews with repository and live-demo links
- Education and experience timeline
- Interactive certificate catalogue
- Contact section
- Scroll progress indicator

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MHazeemShafi/Portfolio.git
```

Navigate into the project directory:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build production version |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
| `npm run test` | Run tests |
